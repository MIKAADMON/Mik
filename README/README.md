WaterMe

האפליקציה שלי נקראת WaterMe והיא נועדה לעזור לאנשים לשתות מספיק מים במהלך היום.

בחרתי בנושא הזה כי לפעמים אני שוכחת לשתות מים ואז יש לי כאבי ראש. רציתי ליצור אפליקציה שתזכיר לי לשתות מים ותעזור לי לעקוב אחרי הכמות שאני שותה.

בינתיים יצרתי שלושה מסכים:

* מסך פתיחה – מציג את הלוגו של האפליקציה עם אנימציה.
* מסך כניסה – מאפשר להכניס שם משתמש וסיסמה.
* מסך הרשמה – מאפשר ליצור משתמש חדש ולבדוק שהפרטים תקינים.

את האפליקציה אני בונה ב-Android Studio בשפת Java ובעזרת XML.

בהמשך אני מתכננת להוסיף תזכורות לשתיית מים ומעקב אחרי כמות המים ששותים בכל יום.
